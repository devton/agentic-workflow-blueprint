🎯 Objetivo do Workflow

Geração Automática de Manuais Visuais HTML

Converte qualquer skill (SKILL.md), contrato de workflow, documento de referência (.md) ou runbook (.md) em um manual visual interativo e autocontido em arquivo único HTML com Tailwind CSS CDN, Dark Mode e componentes em estilo glassmorphism.

✓ Escopo Incluído: Skills, workflows, referências (`.md` ➔ `.html`) e runbooks (`.md` ➔ `.html`) em qualquer repositório.
✗ Fora de Escopo: Construção de aplicações web completas ou SPAs clientes complexas.

🔒 Invariants (Regras Invioláveis)

  • Single-File Self-Contained: O arquivo HTML gerado DEVE ser 100% autocontido utilizando CDN do Tailwind CSS via `
